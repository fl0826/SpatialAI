# Unity Quest 3 应用

空间 AI 助手的 Quest 3 客户端

## 功能模块

- Passthrough 透视
- 手柄 Ray 交互
- 摄像头图像获取
- 网络通信（Backend API）
- 空间 UI 显示

## 开发环境

- Unity 2022.3 LTS+
- Meta Quest SDK
- OpenXR Plugin

## 项目创建

从 0 创建新 Unity 项目，参考官方 Sample：

- Unity-PassthroughCameraApiSamples
  - CameraViewer
  - CameraToWorld
  - MultiObjectDetection

**不要直接在官方 Sample 上开发**，仅作为技术参考
